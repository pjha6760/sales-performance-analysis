# 📊 Sales Performance Dashboard

## Overview
This project is an interactive Sales Performance Dashboard developed using Microsoft Power BI.

The dashboard provides insights into sales performance across different regions, categories, years, customer segments, and products.

## Dashboard Features

- Total Sales
- Total Profit
- Total Customers
- Total Orders
- Profit Margin %
- Products Sold
- Sales by Category
- Sales by Region
- Sales by Year
- Sales by Segment
- Top 10 Products
- Interactive Year and Region slicers

## Tools Used

- Microsoft Power BI
- DAX
- Power Query
- Microsoft Excel

## KPIs

- Total Sales
- Total Profit
- Profit Margin
- Customer Count
- Order Count
- Products Sold
